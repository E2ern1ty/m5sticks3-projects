# WiFi Signal Hunter · WiFi 信号寻踪器

扫描周边 WiFi 并按强度排序；锁定任一信号源进入追踪模式：实时 dBm、历史曲线、
盖革式蜂鸣（越近越急）、重力横屏翻转、3D 导航罗盘（推算 AP 方位与楼层方向）。

## 操作

| 按键 | 列表页 | 追踪页 |
|---|---|---|
| A 短按 | 下移选择（可滚动） | 立即全扫 |
| A 长按 | 过滤隐藏 SSID | 开/关 3D 导航罗盘 |
| B 短按 | 进入追踪 | 返回列表 |
| B 长按 | — | 重置方位投票 |

- 列表顺序固定（首扫按信号排序后不变），标题栏双行：scanning 状态 + 实时电量
- 追踪页单信道快扫 ~4Hz 刷新，EMA 平滑；每 15s 全扫校准信道
- 3D 罗盘：四元数全姿态（任意持握），行走梯度投票推算 AP 三维方位；
  方位环（相对当前指向）+ 仰角梯（楼上/楼下）。**需边走边测，原地转无效。**
