# Bubble Level · 气泡水平仪

把棒子平放桌面检查水平：球滚向低的一侧（垫高球那边），两轴倾角 < 0.3° 时
变绿并蜂鸣，显示 LEVEL。

| 按键 | 功能 |
|---|---|
| A 短按 | 量程 ±2° / ±5° / ±10° |
| B 短按 | 以当前姿态为零点校准（放到已知水平面上按） |
| B 长按 | 清除校准 |

- BMI270 加速度计 + EMA 平滑，分辨率 0.1°
- 校准存 NVS 断电不丢
